# Café Pudim — Landing Page

Landing page de cafeteria criada para a atividade de React + Tailwind CSS.

## Tema
**Café Pudim** — Cafeteria & Doceria artesanal  
Fundo na cor pudim (bege/caramelo quente).

## Tecnologias
- React 19 + Vite
- Tailwind CSS v4 (classes utilitárias + @theme)
- React Icons (Fa, Gi)

## Seções
1. **Header** — Logo, menu (4 opções), botão destaque, menu mobile
2. **Hero** — Título, descrição, CTAs, ilustração
3. **Benefícios** — 4 cards com ícone, título e descrição (Grid)
4. **Cardápio / Produtos** — 4 cards com ícone, nome, descrição, preço e botão
5. **Depoimentos** — 3 cards com foto (iniciais), nome, comentário e estrelas
6. **Footer** — Nome, endereço, horário, redes sociais e copyright

## Conteúdos praticados
- Configuração do Tailwind CSS
- React Icons
- Componentização
- Tipografia, cores, espaçamentos
- Flexbox e Grid
- Responsividade
- Hover, Focus, Transições, Sombras, Border Radius

## Como rodar

```bash
npm install
npm run dev
```
